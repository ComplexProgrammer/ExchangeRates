# Google Play Console: Versiya 3.0.3 (29) Chiqarilish Eslatmalari (Release Notes)

Google Play Console'ning **"Release notes" (Chiqarilish eslatmalari)** maydoniga to'g'ridan-to'g'ri nusxalab qo'yish uchun tayyor XML formatidagi matnlar:

```xml
<tr-TR>
3.0.3 sürümündeki yenilikler:
• Merkez Bankası (CBU) doğrudan yedekleme bağlantısı entegre edildi
• Sunucu kesintilerinde bile döviz kurlarının kesintisiz ve güvenilir yüklenmesi
• Çevrimdışı önbellek ve veri senkronizasyonu geliştirildi
• Genel performans ve kararlılık iyileştirmeleri
</tr-TR>

<en-US>
What's new in version 3.0.3:
• Added automatic direct fallback to Central Bank (CBU) official API
• Uninterrupted exchange rate loading even during server maintenance
• Improved offline caching and network resilience
• General performance and stability improvements
</en-US>

<ru-RU>
Что нового в версии 3.0.3:
• Добавлено прямое резервное подключение к официальному API Центрального банка (ЦБ)
• Бесперебойная загрузка курсов валют даже при сбоях или техработах на сервере
• Улучшена надежность автономного кэширования и синхронизации
• Повышена общая стабильность и производительность
</ru-RU>

<uz-UZ>
3.0.3 versiyasidagi yangiliklar:
• Markaziy bank (MB) rasmiy API'siga to'g'ridan-to'g'ri avtomatik zaxira (fallback) ulandi
• Serverda uzilish yoki profilaktika bo'lganda ham kurslar uzluksiz yuklanadi
• Oflayn kesh va tarmoq barqarorligi yaxshilandi
• Umumiy tezlik va ishonchlilik oshirildi
</uz-UZ>
```
